# Changelog

## 0.1.3 - 2026-11-25

- Added rtemis-gray with white text on medium gray and rtemis-light-gray with black text on light gray, matching VS Code.
- Adjusted syntax colors, comments, selections, and highlights for the new gray backgrounds.

## 0.1.2 - 2026-11-25

- Added rtemis-dark-gray with a lighter charcoal background and adjusted text contrast.
- Made Markdown headings bold and teal across all themes.
- Removed italics from comments and documentation comments across all themes.
- Made Markdown emphasis italic.
- Colored Markdown strikethrough text gray, matching VS Code.
- Colored link URLs blue, matching VS Code.

## 0.1.0 - initial release

- Added rtemis-dark and rtemis-light for Zed.
- Matched the VS Code palette, neutral gray surfaces, and terminal ANSI colors.
- Limited syntax italics to comments.
- Added distinct green/red diff fills and blue modification markers.
