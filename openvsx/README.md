# rtemis on Open VSX

Dark, gray, and light rtemis themes for editors using the Open VSX Registry.

Install [`egenn.rtemis-theme`](https://open-vsx.org/extension/egenn/rtemis-theme),
then choose **rtemis-dark**, **rtemis-dark-gray**, **rtemis-gray**,
**rtemis-light-gray**, or **rtemis-light** with **Preferences: Color Theme**.

All five themes share the VS Code palette, screenshots, and version. See the
[theme overview and screenshots](../vscode/README.md).
